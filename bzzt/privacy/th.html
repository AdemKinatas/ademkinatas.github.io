นโยบายนี้อธิบายว่ามีการประมวลผลข้อมูลใดบ้างเมื่อคุณใช้เกมมือถือ Bzzt! เพราะเหตุใด เก็บไว้นานเท่าใด และคุณมีสิทธิ์อะไรบ้าง ผู้ควบคุมข้อมูลคือ Adem Kınataş คุณติดต่อเราได้ที่ ademkinatas@gmail.com

สรุปสั้น ๆ

  • ไม่มีระบบบัญชี เราไม่เคยขอชื่อ อีเมล หรือหมายเลขโทรศัพท์ของคุณ
  • เกมที่เล่นบนมือถือเครื่องเดียว สถิติ การตั้งค่า และลิสต์การ์ดของคุณเองจะอยู่บนมือถือของคุณ
  • เมื่อเล่นออนไลน์ คุณเป็น ID ผู้เล่นที่ไม่ระบุตัวตน ข้อมูลของล็อบบี้ รวมถึงแชท จะถูกลบเมื่อล็อบบี้ปิด และไม่เกิน 24 ชั่วโมงหลังจากสร้างล็อบบี้
  • แชทในล็อบบี้เป็นข้อความเท่านั้น แอปไม่ใช้ไมโครโฟน กล้อง รูปภาพ รายชื่อติดต่อ หรือตำแหน่งที่แม่นยำของคุณ
  • เวอร์ชันฟรีแสดงโฆษณาจาก Google AdMob การขอความยินยอมและการขออนุญาตติดตามจะเกิดขึ้นหลังจากคุณเล่นเกมแรกจนจบแล้วเท่านั้น ผู้เล่น Premium จะไม่เห็นโฆษณาและจะไม่ถูกถามเลย
  • การตั้งค่า > ข้อมูลของคุณ > ลบข้อมูลของฉัน จะลบ ID ผู้เล่นของคุณและรายการบล็อกของคุณออกจากเซิร์ฟเวอร์ของเรา สิ่งที่ลบไม่ได้มีระบุไว้ด้านล่าง

ข้อมูลที่เก็บไว้บนมือถือของคุณ

ข้อมูลต่อไปนี้อยู่บนมือถือของคุณและไม่ได้ส่งมาให้เรา เว้นแต่หัวข้อด้านล่างจะระบุไว้เป็นอย่างอื่น เมื่อลบแอป ข้อมูลเหล่านี้จะถูกลบไปด้วย

  • สถิติ ความสำเร็จ และเกมที่เล่นล่าสุด
  • เกมที่ยังเล่นไม่จบ เพื่อให้คุณเล่นต่อได้
  • ภาษา เสียง การสั่น และการตั้งค่าอื่น ๆ
  • ลิสต์การ์ดของคุณเอง
  • แพ็กการ์ดที่ดาวน์โหลดแล้ว
  • รายการการ์ดที่คุณเคยเจอแล้ว เพื่อไม่ให้การ์ดซ้ำ
  • ID ผู้เล่นที่ไม่ระบุตัวตนของคุณพร้อมโทเค็นการเข้าถึง และชื่อของผู้เล่นที่คุณบล็อก
  • เวลาที่แสดงโฆษณาครั้งล่าสุด เพื่อให้โฆษณาเว้นระยะห่างกัน และตัวเลือกด้านโฆษณาของคุณ

ID ผู้เล่นที่ไม่ระบุตัวตนของคุณ

ครั้งแรกที่คุณเล่นออนไลน์หรือดาวน์โหลดแพ็กการ์ด เซิร์ฟเวอร์ของเราจะสร้าง ID ผู้เล่นแบบสุ่มพร้อมโทเค็นการเข้าถึง ID นี้ไม่ได้เชื่อมโยงกับชื่อของคุณ บัญชี Apple ของคุณ หรือตัวระบุโฆษณาของอุปกรณ์ ID นี้แสดงอยู่ในการตั้งค่า เพื่อให้คุณแจ้งได้เมื่อเขียนถึงเรา

ข้อมูลที่ประมวลผลเมื่อคุณเล่นออนไลน์

เมื่อคุณสร้างหรือเข้าร่วมล็อบบี้ เซิร์ฟเวอร์ของเราจะประมวลผลข้อมูลต่อไปนี้เพื่อให้เกมทำงานได้:

  • ID ผู้เล่นของคุณและชื่อเล่นที่คุณเลือก
  • รหัสล็อบบี้ ทีมของคุณ และสิ่งที่คุณทำในเกม
  • ข้อความแชทที่คุณส่ง และลิสต์การ์ดของคุณเองหากคุณนำมาเล่นในล็อบบี้
  • รายการการ์ดที่คุณเคยเจอแล้ว เพื่อให้สำรับของล็อบบี้เลี่ยงการ์ดเหล่านั้น ผู้เล่นคนอื่นจะไม่เห็นรายการนี้
  • ที่อยู่ IP ของคุณ ซึ่งส่งถึงเซิร์ฟเวอร์ทุกครั้งที่เชื่อมต่อ เราใช้เพื่อจำกัดการใช้งานในทางที่ผิด (คำขอมากเกินไป) เท่านั้น และไม่ได้เก็บไว้คู่กับ ID ผู้เล่นของคุณ

ระยะเวลาเก็บข้อมูลล็อบบี้

ล็อบบี้จะปิดเมื่อไม่มีความเคลื่อนไหว 2 ชั่วโมง เมื่อไม่มีใครเชื่อมต่ออยู่ 30 นาที หรือเมื่อครบ 24 ชั่วโมงหลังจากสร้าง แล้วแต่ว่าอย่างใดถึงก่อน ล็อบบี้ฝึกซ้อมกับบอตจะปิดเมื่อคุณออกจากล็อบบี้ เมื่อล็อบบี้ปิด ข้อมูลทั้งหมดของล็อบบี้จะถูกลบทันที ได้แก่ สมาชิก ชื่อเล่น แชท สถานะเกม และรายการการ์ดที่เคยเจอ ข้อความของคุณจะแสดงให้เฉพาะผู้เล่นในล็อบบี้นั้นเห็นเท่านั้น

การ์ด แพ็ก และการอัปเดต

แอปจะถามเซิร์ฟเวอร์ของเราเป็นระยะว่ามีการ์ดใหม่หรือการ์ดที่แก้ไขแล้วหรือไม่ การตรวจสอบนี้ไม่ส่ง ID ผู้เล่นและไม่ส่งข้อมูลเกม การดาวน์โหลดแพ็กการ์ด Premium จะส่งโทเค็นของ ID ผู้เล่นของคุณ เพื่อให้เซิร์ฟเวอร์ตรวจสอบกับ RevenueCat ว่าคุณมี Premium เช่นเดียวกับการเชื่อมต่ออื่น ๆ ที่อยู่ IP ของคุณจะส่งถึงเซิร์ฟเวอร์

การรายงาน

เมื่อคุณรายงานผู้เล่น เราจะเก็บ ID ผู้เล่นของคุณ ID ของผู้เล่นที่ถูกรายงาน รหัสล็อบบี้ เหตุผลที่คุณเลือก ข้อความที่ถูกรายงาน (เซิร์ฟเวอร์อ่านจากแชทของล็อบบี้ หรือหากอยู่นอกล็อบบี้ คือข้อความที่คุณพิมพ์) และเวลา ชื่อเล่นจะไม่ถูกเก็บไว้กับการรายงาน

การรายงานใหม่ทุกครั้งจะส่งทางอีเมลถึงผู้พัฒนา อีเมลประกอบด้วยเวลา เหตุผล ID ของผู้เล่นที่ถูกรายงาน รหัสล็อบบี้ หมายเลขการรายงาน และข้อความที่ถูกรายงานไม่เกิน 200 ตัวอักษร อีเมลนี้ไม่มี ID ผู้เล่นของคุณ การรายงานจะถูกลบโดยอัตโนมัติเมื่อครบ 12 เดือนหลังจากยื่น เว้นแต่มีหน้าที่ตามกฎหมายที่ต้องเก็บไว้นานกว่านั้น

การบล็อก

เมื่อคุณบล็อกผู้เล่น เซิร์ฟเวอร์ของเราจะเก็บคู่ ID ผู้เล่นไว้เพื่อให้คุณไม่เห็นข้อความของผู้เล่นคนนั้นอีก และมือถือของคุณจะเก็บชื่อของผู้เล่นที่ถูกบล็อกไว้ เพื่อให้คุณเลิกบล็อกได้ในการตั้งค่า การบล็อกจะคงอยู่จนกว่าคุณจะเลิกบล็อกหรือลบข้อมูลของคุณ คุณบล็อกผู้เล่นได้สูงสุด 500 คน

การลบข้อมูลของคุณ

การตั้งค่า > ข้อมูลของคุณ > ลบข้อมูลของฉัน จะทำสิ่งต่อไปนี้ทันที:

  • คุณจะออกจากล็อบบี้ที่อยู่ในขณะนั้น
  • การบล็อกทั้งหมดที่คุณทำไว้จะถูกลบออกจากเซิร์ฟเวอร์ของเรา
  • ID ผู้เล่นของคุณในทุกการรายงานที่คุณยื่นจะถูกแทนที่ด้วยคำว่า "ลบแล้ว"
  • เราเก็บลายนิ้วมือแบบทางเดียว (แฮช) ของ ID ผู้เล่นของคุณไว้ เพื่อไม่ให้โทเค็นเดิมถูกนำกลับมาใช้ได้อีก โดยไม่เก็บตัว ID เอง
  • มือถือของคุณจะลืม ID ผู้เล่น โทเค็นของ ID นั้น และชื่อของผู้เล่นที่คุณบล็อก ID ใหม่จะถูกสร้างขึ้นในครั้งถัดไปที่คุณเล่นออนไลน์หรือดาวน์โหลดแพ็ก

สิ่งที่การลบไม่ได้ลบออก

  • การรายงานเกี่ยวกับคุณที่ผู้เล่นคนอื่นยื่นไว้: เก็บไว้เพื่อการดูแลความเรียบร้อยไม่เกิน 12 เดือน
  • การบล็อกที่ผู้เล่นคนอื่นทำไว้กับ ID เดิมของคุณ
  • ล็อบบี้ที่ยังเปิดอยู่จะเก็บสำเนาของตัวเองไว้จนกว่าจะปิด และไม่เกิน 24 ชั่วโมงหลังจากสร้างล็อบบี้
  • การซื้อและการสมัครรับของคุณ ซึ่งผูกอยู่กับบัญชี Apple ของคุณ การลบข้อมูลไม่ได้ยกเลิกการสมัครรับ RevenueCat ยังเก็บบันทึกการซื้อของตนไว้
  • สถิติ การตั้งค่า และลิสต์การ์ดบนมือถือของคุณ: ลบแอปเพื่อลบข้อมูลเหล่านี้

โฆษณา

เวอร์ชันฟรีแสดงโฆษณาผ่าน Google AdMob ทาง Google อาจประมวลผลตัวระบุโฆษณาของอุปกรณ์ (เฉพาะเมื่อคุณอนุญาตให้ติดตาม) ที่อยู่ IP ตำแหน่งโดยประมาณที่ได้จากที่อยู่ IP ข้อมูลอุปกรณ์ การโต้ตอบกับโฆษณา และข้อมูลการวินิจฉัย

จะไม่มีอะไรเกี่ยวกับโฆษณาเกิดขึ้นก่อนที่คุณจะเล่นเกมแรกจบ เมื่อกลับมาที่หน้าแรกหลังเกมนั้น แอปจะแสดงแบบฟอร์มขอความยินยอมของ Google ในกรณีที่ภูมิภาคของคุณกำหนด แล้วจึงแสดงคำขออนุญาตติดตามของ Apple โฆษณาจะปรับให้เหมาะกับคุณก็ต่อเมื่อคุณอนุญาตให้ติดตามและยินยอมรับโฆษณาที่ปรับให้เหมาะกับคุณเท่านั้น หากไม่เช่นนั้น คุณอาจยังเห็นโฆษณาอยู่ แต่จะไม่ใช่โฆษณาที่ปรับให้เหมาะกับคุณ คุณเปลี่ยนตัวเลือกได้ที่การตั้งค่า > การตั้งค่าโฆษณา สำหรับ Premium จะไม่มีการเริ่มทำงาน SDK โฆษณาเลย คือไม่มีโฆษณา ไม่มีแบบฟอร์มขอความยินยอม และไม่มีคำขออนุญาตติดตาม

การซื้อและการสมัครรับ

Apple เป็นผู้ดำเนินการชำระเงินทั้งหมด เราไม่เคยเห็นข้อมูลบัตรของคุณ RevenueCat แจ้งแอปและเซิร์ฟเวอร์ของเราว่าคุณมี Premium หรือไม่ โดยประมวลผลผลิตภัณฑ์ที่คุณซื้อ ธุรกรรมของคุณ และ ID การซื้อที่สร้างแบบทางเดียวจากโทเค็นผู้เล่นของคุณ ผู้เล่นคนอื่นจึงไม่สามารถค้นหาการซื้อของคุณจาก ID ผู้เล่นได้

Premium รายสัปดาห์และรายเดือนเป็นการสมัครรับที่ Apple ต่ออายุและเรียกเก็บเงินโดยอัตโนมัติจนกว่าคุณจะยกเลิกในการตั้งค่าบัญชี Apple ส่วนแบบตลอดชีพเรียกเก็บเงินครั้งเดียว

ผู้ให้บริการและการโอนข้อมูลไปต่างประเทศ

ข้อมูลจะถูกแบ่งปันกับผู้ให้บริการด้านล่างนี้เท่านั้น และเท่าที่จำเป็นต่อบริการของแต่ละราย เซิร์ฟเวอร์ของผู้ให้บริการอาจอยู่นอกประเทศของคุณ การโอนข้อมูลอาศัยมาตรการคุ้มครองที่กฎเกณฑ์ด้านการคุ้มครองข้อมูลที่ใช้บังคับกำหนดไว้

  • Cloudflare: เซิร์ฟเวอร์เกม บันทึกล็อบบี้และการดูแลความเรียบร้อย การดาวน์โหลดการ์ด และการส่งอีเมลรายงาน
  • Google: โฆษณา AdMob และแบบฟอร์มขอความยินยอม กล่องจดหมายของผู้พัฒนาที่รับอีเมลรายงานอยู่บน Gmail
  • RevenueCat: การตรวจสอบการซื้อและการสมัครรับ
  • Apple: การจัดจำหน่ายแอป การชำระเงิน การสมัครรับ และคำขออนุญาตติดตาม

เราประมวลผลข้อมูลเพื่อให้บริการเกม (การปฏิบัติตามสัญญา) เพื่อรักษาความปลอดภัยของเกมและป้องกันการใช้งานในทางที่ผิด (ประโยชน์โดยชอบด้วยกฎหมาย) เพื่อปฏิบัติตามหน้าที่ตามกฎหมาย และอาศัยความยินยอมของคุณในกรณีที่ต้องได้รับความยินยอม เช่น โฆษณาที่ปรับให้เหมาะกับคุณ นโยบายนี้ยังเป็นประกาศแจ้งข้อมูลตามกฎหมายคุ้มครองข้อมูลส่วนบุคคลฉบับที่ 6698 ของตุรกี (KVKK) และตาม GDPR ในกรณีที่ใช้บังคับ

ระยะเวลาการเก็บรักษา

  • ข้อมูลล็อบบี้และแชท: จนกว่าล็อบบี้จะปิด และไม่เกิน 24 ชั่วโมงหลังจากสร้างล็อบบี้
  • การรายงาน: 12 เดือน
  • การบล็อก: จนกว่าจะเลิกบล็อก หรือจนกว่าผู้เล่นที่บล็อกจะลบข้อมูลของตน
  • ลายนิ้วมือของ ID ผู้เล่นที่ถูกลบ: เก็บไว้ เพื่อให้โทเค็นเดิมใช้งานไม่ได้
  • บันทึกการซื้อ: Apple และ RevenueCat เก็บไว้ตามนโยบายของตนและตามที่กฎหมายกำหนด

สิทธิ์ของคุณ

ขึ้นอยู่กับกฎหมายของประเทศของคุณ คุณอาจมีสิทธิ์เข้าถึง แก้ไข หรือลบข้อมูลของคุณ คัดค้านหรือขอให้จำกัดการประมวลผล ขอโอนย้ายข้อมูล และถอนความยินยอม ลบข้อมูลของฉันในการตั้งค่าจะลบข้อมูลให้ทันที สำหรับเรื่องอื่น ๆ โปรดเขียนถึง ademkinatas@gmail.com พร้อม ID ผู้เล่นที่แสดงในการตั้งค่า หากไม่มี ID นี้ เราจะไม่สามารถค้นหาข้อมูลที่เชื่อมโยงกับคุณได้ คุณยังร้องเรียนต่อหน่วยงานคุ้มครองข้อมูลได้ด้วย สำหรับตุรกีคือหน่วยงานคุ้มครองข้อมูลส่วนบุคคลของตุรกี (KVKK)

เด็ก

ความปลอดภัย

การเชื่อมต่อกับเซิร์ฟเวอร์ของเรามีการเข้ารหัส และการเข้าถึงข้อมูลที่จัดเก็บไว้มีการจำกัด ไม่มีระบบใดปลอดภัยได้อย่างสมบูรณ์ เราจึงไม่สามารถรับประกันความปลอดภัยได้อย่างเด็ดขาด
