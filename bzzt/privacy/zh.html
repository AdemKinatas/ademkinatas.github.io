本政策说明你在使用 Bzzt! 手机游戏时会处理哪些数据、为什么处理、保存多久，以及你享有哪些权利。数据控制者为 Adem Kınataş。你可以通过 ademkinatas@gmail.com 联系我们。

简要说明

  • 没有账号。我们从不索要你的姓名、电子邮箱或电话号码。
  • 在一部手机上进行的游戏、你的统计数据、设置以及你自己的卡牌列表，都只保存在你的手机上。
  • 在线时，你只是一个匿名玩家 ID。房间数据（包括聊天）会在房间关闭时删除，最迟在房间创建 24 小时后删除。
  • 房间聊天仅支持文字。本应用不使用你的麦克风、相机、照片、通讯录或精确位置。
  • 免费版会显示来自 Google AdMob 的广告。只有在你第一次完整打完一局游戏之后，才会询问广告同意和跟踪；Premium 玩家看不到广告，也不会被询问。
  • “设置 > 你的数据 > 删除我的数据”会从我们的服务器删除你的玩家 ID 和你做出的屏蔽。无法删除的内容见下文。

保存在你手机上的数据

以下数据保存在你的手机上，不会发送给我们，下文各节另有说明的除外。删除应用时，这些数据也会一并删除。

  • 统计数据、成就和最近的游戏
  • 未完成的游戏，方便你继续
  • 语言、声音、振动及其他设置
  • 你自己的卡牌列表
  • 已下载的词包
  • 你已看过的卡牌列表，避免卡牌重复出现
  • 你的匿名玩家 ID 及其访问令牌，以及你屏蔽的玩家的名字
  • 上次显示广告的时间（用于拉开广告间隔），以及你的广告选择

你的匿名玩家 ID

你第一次在线游戏或下载词包时，我们的服务器会生成一个随机的玩家 ID 和一个访问令牌。它与你的姓名、你的 Apple 账户或设备的广告标识符均无关联。玩家 ID 显示在“设置”中，你写信联系我们时可以附上它。

在线游戏时处理的数据

当你创建或加入房间时，为了让游戏正常运行，我们的服务器会处理以下数据：

  • 你的玩家 ID 和你选择的昵称
  • 房间码、你所在的队伍以及你在游戏中的操作
  • 你发送的聊天消息；如果你在房间里使用自己的卡牌列表，也包括这些列表
  • 你已看过的卡牌列表，让房间的牌组避开这些卡牌。其他玩家永远看不到这份列表
  • 你的 IP 地址，每次连接时都会到达服务器。我们只用它来限制滥用（请求过多），不会把它与你的玩家 ID 一起保存

房间数据保存多久

房间在以下任一情况先发生时关闭：2 小时无活动、30 分钟内无人连接，或创建满 24 小时。和机器人一起的练习房间在你离开时关闭。房间关闭时，其所有数据会立即删除：成员、昵称、聊天、游戏状态和已看卡牌列表。你的消息只会显示给该房间里的玩家。

卡牌、词包和更新

应用会不时向我们的服务器查询是否有新的或修正过的卡牌。这项查询不会发送玩家 ID，也不会发送游戏数据。下载 Premium 词包时，应用会发送你的玩家 ID 的令牌，以便服务器通过 RevenueCat 核实你是否拥有 Premium。和任何连接一样，你的 IP 地址会到达服务器。

举报

当你举报一名玩家时，我们会保存：你的玩家 ID、被举报玩家的 ID、房间码、你选择的原因、被举报的聊天消息（由服务器从房间聊天中读取；不在房间内时，则为你输入的文字）以及时间。举报记录中不保存昵称。

每一条新举报都会通过电子邮件发送给开发者。邮件包含时间、原因、被举报玩家的 ID、房间码、举报编号以及被举报消息的最多 200 个字符，但不包含你的玩家 ID。举报会在提交 12 个月后自动删除，除非法律义务要求将某条举报保存更久。

屏蔽

当你屏蔽一名玩家时，我们的服务器会保存这一对玩家 ID，让你不再看到该玩家的消息；你的手机会保存被屏蔽玩家的名字，方便你在“设置”中解除屏蔽。屏蔽会一直保留，直到你解除屏蔽或删除你的数据。你最多可以屏蔽 500 名玩家。

删除你的数据

“设置 > 你的数据 > 删除我的数据”会立即完成以下操作：

  • 你会离开所在的任何房间
  • 你设置的所有屏蔽都会从我们的服务器上删除
  • 你提交过的每一条举报中，你的玩家 ID 都会被替换为“已删除”
  • 我们会保留你的玩家 ID 的单向指纹（哈希值），确保旧令牌永远无法再被使用。玩家 ID 本身不会保留
  • 你的手机会清除玩家 ID、令牌以及你屏蔽的玩家的名字。下次你在线游戏或下载词包时，会生成新的 ID

删除操作不会移除的内容

  • 其他玩家针对你提交的举报：为审核需要最多保留 12 个月
  • 其他玩家针对你旧 ID 设置的屏蔽
  • 仍在开放的房间会保留其副本，直到房间关闭，最迟在房间创建 24 小时后
  • 你的购买和订阅，它们属于你的 Apple 账户。删除数据不会取消订阅。RevenueCat 会保留其购买记录
  • 你手机上的统计数据、设置和卡牌列表：删除应用即可移除

广告

免费版通过 Google AdMob 显示广告。Google 可能会处理你设备的广告标识符（仅在你允许跟踪时）、IP 地址、据此推断的大致位置、设备信息、广告互动和诊断数据。

在你完整打完第一局游戏之前，不会发生任何与广告相关的事。之后回到主页时，如果你所在地区有要求，应用会显示 Google 的同意表单，接着显示 Apple 的跟踪请求。只有在你允许跟踪并同意个性化广告时，广告才会个性化；否则你仍可能看到广告，但不会是个性化广告。你可以在“设置 > 广告偏好”中更改选择。拥有 Premium 时，广告 SDK 根本不会启动：没有广告，没有同意表单，也没有跟踪请求。

购买和订阅

所有付款都由 Apple 处理，我们永远看不到你的银行卡信息。RevenueCat 会告诉应用和我们的服务器你是否拥有 Premium。为此，它会处理你购买的产品、你的交易记录，以及一个由你的玩家令牌单向派生出的购买 ID，这样其他玩家就无法通过你的玩家 ID 查到你的购买情况。

Premium 周订阅和月订阅是由 Apple 自动续期并扣费的订阅，直到你在 Apple 账户设置中取消为止。终身版只扣费一次。

服务提供商和跨境传输

数据只会与以下服务提供商共享，且仅限其服务所需的范围。它们的服务器可能位于你所在的国家或地区之外。跨境传输依据适用的数据保护法规所规定的保障措施进行。

  • Cloudflare：游戏服务器、房间和审核记录、卡牌下载以及举报邮件的发送
  • Google：AdMob 广告和同意表单；开发者接收举报邮件的邮箱位于 Gmail
  • RevenueCat：核实购买和订阅
  • Apple：应用分发、付款、订阅和跟踪请求

法律依据

我们处理数据是为了提供游戏（履行合同）、保障游戏安全和防止滥用（合法利益）、履行法律义务，以及在需要同意的情况下（例如个性化广告）基于你的同意进行处理。本政策同时作为土耳其第 6698 号《个人数据保护法》（KVKK）以及在适用情况下 GDPR 所要求的告知说明。

保存期限

  • 房间数据和聊天：保存到房间关闭为止，最迟在房间创建 24 小时后删除
  • 举报：12 个月
  • 屏蔽：保存到被解除，或设置屏蔽的玩家删除自己的数据为止
  • 已删除玩家 ID 的指纹：保留，确保旧令牌始终无法使用
  • 购买记录：由 Apple 和 RevenueCat 按其各自政策及法律要求保存

你的权利

根据你所在国家或地区的法律，你可能享有访问、更正或删除你的数据，反对或限制处理，数据可携带以及撤回同意的权利。“设置”中的“删除我的数据”可以立即完成删除。如有其他请求，请发送邮件至 ademkinatas@gmail.com，并附上“设置”中显示的玩家 ID；没有它，我们就无法找到与你相关的数据。你也可以向你所在地的数据保护机构投诉；在土耳其，该机构为个人数据保护局（KVKK）。

儿童

线上房间和聊天不面向 13 岁以下的儿童；如果你所在国家或地区规定的年龄更高，则以该年龄为准。如果你认为有儿童向我们提供了数据，请发送邮件至 ademkinatas@gmail.com，我们会将其删除。

安全

与我们服务器之间的连接经过加密，对已存储数据的访问也受到限制。没有任何系统是绝对安全的，因此我们无法保证绝对安全。

政策变更

我们可能会更新本政策。现行文本及其生效日期始终公布在本页面，重要变更会在应用内告知。
