データの削除 — Pencil Punch

最終更新日：2026年11月14日

Pencil Punch には会員登録もアカウントもありません。本アプリは、オンライン対戦、コイン、ポーズのために匿名のプレイヤーを作成します。このプレイヤーは、本アプリ内でいつでもご自身で削除できます。

アプリ内で削除する(最も早い方法)

  • Pencil Punch を開き、設定をタップします。
  • 「あなたのデータ」の項目を探します。
  • 「データを削除」をタップして、確定します。

削除はすぐに行われます。インターネット接続が必要です。

削除されるもの

  • 当方のサーバー上にある匿名のプレイヤー(ファイター名、コイン、XP、勝ち数、負け数を含む)。
  • 購入または解放したポーズ、およびリワード動画の記録。
  • お客様のプレイヤー ID が記載された対戦記録と同じ組み合わせのカウントは、1 件ずつ削除されるわけではありません。2 日間だけ保持され、その後自動的に消去されます。

削除後、本アプリは新しいファイター名を持つ、空の新しいプレイヤーを開始します。以前のコイン、XP、ポーズを復元することはできません。

削除されないもの

  • 購入記録。法律の定めにより、Apple と RevenueCat が保持します。Premium はお客様の Apple Account に属しており、「購入を復元」で復元できます。データを削除しても、サブスクリプションは解約されません。iPhone の 設定 → ご自身の名前 → サブスクリプション から解約してください。
  • お使いの iPhone にのみあるデータ：設定。すべてを消去するには、本アプリを削除してください。
  • Google が広告のために保持するデータや、Cloudflare が自社のログに保持するデータ。それぞれのポリシーに従います(プライバシーポリシーを参照)。

アプリを使わずに削除する

アプリを開けなくなった場合、以前のプレイヤーにアクセスすることはできません。再インストールしたアプリは新しいプレイヤーを開始し、当方は ID がなければ匿名のプレイヤーを特定できません。365 日間使われていないプレイヤーは、自動的に削除されます。プレイヤー ID がわかる場合は、件名を「データを削除」として、その ID を添えて ademkinatas@gmail.com までご連絡ください。30 日以内にご返信します。RevenueCat にある購入データの削除をご希望の場合は、同じアドレスまでご連絡ください。当方からご依頼を転送します。
